# Smart Nursery Assistant

**Program:** IEEE WIE JS Mentorship Program 2026  
**Track:** AI & Programming  
**Project Status:** Task 03 — Documentation and Planning

## Project Overview

Smart Nursery Assistant is an AI-assisted responsive web application designed primarily for nursery owners. It helps the owner identify supported plants from images, assess visible plant problems, access plant-care information, receive qualitative watering guidance, and manage individual plant records and inspection histories. It also includes a conversational plant-care assistant that allows the owner to ask questions and receive explanations and care recommendations in Arabic or English, based on available plant information, inspection results, records, and documented knowledge. The application is designed primarily for use through an Android smartphone browser. The first version focuses on image-based AI assistance and practical nursery support without requiring IoT devices, sensors, or automatic irrigation.
