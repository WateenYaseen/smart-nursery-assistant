# Smart Nursery Assistant — Screens

**Program:** IEEE WIE JS Mentorship Program 2026  
**Track:** AI & Programming  
**Status:** Updated after Task 03 Fresh-Chat Test

## S1. Home Dashboard
Displays an overview of registered plants, plants that may need attention, and access to the main actions.  
**Requirements served:** R7, R10, R11, R13.

## S2. Plant List
Displays registered individual plants and allows the owner to select the specific plant they want to inspect or manage.  
**Requirements served:** R7, R13.

## S3. Add New Plant
Allows the owner to create a separate record for a new individual plant.  
**Requirements served:** R7, R13.

## S4. Plant Inspection
Allows the owner to select an image for the selected plant and submit it for assessment; the system may request another image or relevant answers when needed.  
**Requirements served:** R1, R2, R6, R13.

## S5. Inspection Results
Displays the predicted common plant name, confidence information, possible visible conditions, supporting symptoms, care and treatment guidance, and qualitative watering assessment. It also provides access to the conversational assistant, allowing the owner to ask follow-up questions about the selected plant in Arabic or English.  
**Requirements served:** R1, R2, R3, R4, R5, R6, R14.

## S6. Plant Details and History
Displays the selected plant's information, previous inspections and images, owner-entered care actions, and suggested next actions. It also allows the owner to continue a conversation with the assistant using the available information about that plant.  
**Requirements served:** R7, R8, R9, R10, R11, R14.

## Not Building

A separate administration dashboard, sensor-monitoring screens, IoT control screens, native Android application screens, payment screens, and social or community features are not included in the first version.
