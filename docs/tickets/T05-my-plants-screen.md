# T05 — My Plants Screen

**Priority:** High  
**Estimate:** 1 working day  
**Status:** Planned

## Why

The owner needs one place to view and access all registered individual plants.

## Done When

- The My Plants screen follows the approved UI design.
- Saved plant records are retrieved and displayed.
- Each plant is displayed as a separate item.
- Each item displays the plant name.
- An available plant image is displayed when present.
- Available follow-up information or latest inspection date is displayed.
- Selecting a plant opens its Plant Details screen.
- An Add Plant action opens the Add Plant screen.
- An empty state is displayed when no plants are registered.
- A loading state is displayed while plant records are retrieved.
- An error state provides a clear message and Retry action.

## Touches

- My Plants screen.
- Plant list component.
- Plant data model.
- Plant retrieval operation.
- Plant Details navigation.
- Empty, loading, and error states.

## Notes

Search and filtering may be added if time and implementation requirements allow. They are not required for the basic plant-list workflow.
