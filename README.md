# Smart Nursery Assistant 

An AI-powered assistant designed to help nursery owners identify plants, assess selected visible plant conditions, access plant-care guidance, and maintain records for individual plants.

The project focuses on making plant care more accessible through image-based AI features and conversational interaction, with Arabic as the primary language and English as a secondary language.

## Problem

Managing a nursery requires continuous attention to individual plants. Nursery owners may spend considerable time searching for plant information, identifying possible problems, and deciding what care a plant needs.

Existing tools provide useful features, but the proposed project focuses on combining plant identification, visible condition assessment, conversational guidance, and individual plant records in one simple workflow.

## Proposed Features

- **Plant Identification:** Identify supported plant types using images.
- **Condition Assessment:** Assess selected visible plant conditions supported by available data.
- **Care Guidance:** Provide cautious plant-care information and ask follow-up questions when necessary.
- **Individual Plant Records:** Generate unique IDs and maintain separate records for individual plants.
- **Plant History:** Preserve previous observations and records.
- **Photo Matching:** Attempt to match new photos to existing plant records, requesting user confirmation when uncertain.
- **Bilingual Interaction:** Prioritize Arabic with English as a secondary language.

## Project Scope

The initial version will focus on a limited number of plant types and visible conditions based on suitable dataset availability and evaluation results.

Features such as IoT integration, automatic irrigation, environmental sensors, inventory management, and large-scale agricultural operations are outside the initial scope.

## Technology and Data

Potential public datasets, including Kaggle datasets, will be investigated.

Dataset selection will consider:
- Image quality and label reliability.
- Dataset licensing and usage permissions.
- Supported plant types and condition categories.
- Relevance to the intended nursery environment.

Training, validation, and testing data will be separated appropriately. Local nursery images reserved for independent evaluation will not be used for model training or tuning.

The final technology stack and supported categories have not yet been selected.
